# ФІШЕР — personal control v14

Виправлено баг синхронізації ручного вибору дат.

## Що було
У календарі могло бути:
«Обрані дати: 4»,
а в кроці 2:
«Ще немає обраних дат».

## Що виправлено
Крок 2 тепер бере дати напряму з набору реально натиснутих дат у календарі.

Після кожного кліку:
1. дата додається / прибирається;
2. список «Обрані дати» оновлюється;
3. крок 2 одразу оновлюється;
4. для кожної дати з'являються налаштування пари, виду заняття й аудиторії.

Так само під час збереження серії використовуються саме реально вибрані дати,
тому серія не залежить від окремого поля «Дата».
