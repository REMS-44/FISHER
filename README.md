# ФІШЕР — personal control v2

Нова версія персонального CONTROL у світлому редакційному дизайні з темною боковою панеллю.

## Є
- Головна
- Мій тиждень
- Заняття з повним відображенням групи, дисципліни, теми і місця
- Справи
- Проєкти
- Нотатки
- Додавання / редагування / видалення
- Пошук
- Експорт та імпорт даних
- Мобільна версія
- PWA

## Дані
Поки зберігаються в localStorage браузера.
