# ФІШЕР — personal control v13

Перероблено режим «Обрати конкретні дати».

## Що виправлено
У v12 була помилка: зверху могло показувати «Обрано дат: 4», а нижче — «Оберіть хоча б одну дату».
Причина виправлена: ручний вибір дат більше не залежить від окремого поля «Дата».

## Новий зрозумілий сценарій

### Крок 1. Оберіть потрібні дати
- натискайте на числа;
- обрані дати стають темними і мають галочку;
- можна переходити між місяцями;
- під календарем видно список усіх обраних дат;
- будь-яку дату можна прибрати хрестиком;
- є «Очистити всі».

### Крок 2. Перевірте дати та налаштуйте винятки
Обрані дати автоматично з'являються нижче.
Для кожної можна:
- змінити пару;
- змінити вид заняття;
- змінити аудиторію;
- пропустити дату.

Старі дані не змінюються.
