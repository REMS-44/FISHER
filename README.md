# ФІШЕР — CONTROL v18

## 1. Безпека даних

### Автоматичні резервні копії
Перед кожною зміною CONTROL зберігає попередній стан даних у локальну історію.

Зберігаються останні 10 різних станів.

### Історія копій
У меню «Швидкий доступ»:
- «Зробити резервну копію»
- «Історія копій»
- «Експорт даних»
- «Імпорт даних»

В історії видно:
- дату й час;
- тип копії;
- кількість занять, справ, проєктів і нотаток;
- кнопку «Відновити».

Перед відновленням поточний стан теж автоматично архівується.

### Ручна копія
Кнопка «Зробити резервну копію»:
1. додає поточний стан до локальної історії;
2. одразу завантажує JSON-файл виду:
   `FISHER_2026-08-14_15-58.json`.

## 2. Дисципліни

Додано окремий розділ «Дисципліни».

Нічого повторно вводити не потрібно.
CONTROL автоматично групує заняття за:
`Дисципліна + Група`.

Наприклад:
`Режисура естради і шоу · РЕМС-44`

### Для кожної дисципліни видно:
- загальну кількість занять;
- скільки вже минуло;
- скільки залишилось;
- скільки тем уже внесено;
- наступне заняття.

### Усередині дисципліни:
- усі заняття семестру по порядку;
- дата;
- номер пари і час;
- вид заняття;
- аудиторія;
- тема;
- «Що підготувати»;
- статус: минуло / сьогодні / попереду;
- швидке редагування конкретного заняття.

### Семестри
CONTROL автоматично визначає семестр за датами занять:
- осінній: серпень — січень;
- весняний: лютий — липень.

Можна перемикатися між семестрами у верхній частині розділу.

Старі дані збережені: основний localStorage-ключ не змінено.
