# ФІШЕР — personal control v11

Новий пакет функцій:

## 1. Повторювані заняття
При створенні заняття можна вибрати:
- не повторювати;
- щотижня;
- дату, до якої створювати заняття.

CONTROL автоматично створить усі заняття серії.

## 2. Шаблони занять
Можна зберегти налаштування заняття як шаблон:
- група;
- дисципліна;
- номер пари / час;
- вид заняття;
- аудиторія;
- місце;
- нагадування.

При наступному створенні заняття шаблон підставляє ці поля автоматично.
На сторінці «Заняття» є список шаблонів, їх можна видаляти.

## 3. Нагадування про підготовку
Для заняття можна вибрати:
- не нагадувати;
- у день заняття;
- за 1, 2, 3 або 7 днів.

Якщо заповнено «Що підготувати», на Головній з'являється окремий блок
«Підготувати до занять» у потрібний період.

## 4. Перевірка конфліктів
При збереженні заняття CONTROL перевіряє, чи вже є інше заняття
в той самий час. Для повторюваної серії перевіряються всі дати.
При конфлікті система показує, з чим саме перетинається заняття,
і питає, чи все одно зберігати.

## Додатково
Прибрано зайву кнопку «Відкрити календар окремо» — календар уже є на Головній.

Старі дані збережені: ключ localStorage не змінено.
