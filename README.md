# ФІШЕР — CONTROL v19

## 1. Швидке створення з будь-якого місця

Велика кнопка «+» тепер постійно доступна і на комп'ютері, і на телефоні.

Після натискання:
- Заняття
- Справа
- Проєкт
- Нотатка

CONTROL пам'ятає активну дату.

Наприклад:
1. відкрили 18 вересня;
2. перейшли в інший розділ;
3. натиснули «+»;
4. для заняття / справи / проєкту автоматично підставиться 18 вересня.

Нотатка не має прив'язки до дати.

## 2. Автоматичні кольори груп

Кольори не потрібно задавати вручну.

Кожна назва групи автоматично отримує стабільний відтінок.
Одна й та сама група завжди має той самий колір.

Колір використовується:
- у картці заняття в календарі;
- у крапці біля назви групи;
- у блоці «Сьогодні».

Над календарем автоматично показується легенда груп поточного місяця.

## 3. «Завтра»

Між верхніми картками і календарем є компактна смуга «ЗАВТРА».

Вона показує:
- дату;
- кількість занять;
- кількість справ;
- кількість пунктів «Що підготувати».

Натискання відкриває завтрашній день на весь екран.

Старі дані та резервні копії не змінюються.
