# ФІШЕР — personal control v12

Гнучкі серії занять.

## Режими
- Один раз
- Щотижня
- Раз на два тижні
- Обрати конкретні дати

## Перед створенням серії
CONTROL показує всі дати серії.

Для кожної окремої дати можна:
- залишити базові налаштування;
- змінити номер пари / час;
- змінити вид заняття;
- змінити аудиторію;
- ввести власний вид заняття;
- ввести власну аудиторію;
- зняти галочку і пропустити цю дату.

## Обрати конкретні дати
Є окремий міні-календар. Можна переходити між місяцями і клацати будь-які потрібні дати.

## Редагування вже створеної серії
У формі заняття є вибір:
- тільки це заняття;
- це заняття і всі наступні;
- уся серія.

Тому якщо, наприклад, із жовтня змінюється аудиторія, достатньо відкрити перше жовтневе заняття,
змінити аудиторію і вибрати «це заняття і всі наступні».

## Видалення серії
При видаленні заняття із серії CONTROL питає:
1 — тільки це;
2 — це і всі наступні;
3 — всю серію.

Старі дані та шаблони не зникають: ключ localStorage не змінено.
