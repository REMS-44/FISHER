# ФІШЕР — personal control v9

Календар тепер працює як інформаційна панель, а не як набір лічильників.

У кожній клітинці дня одразу показуються ВСІ записи.

## Заняття
- номер пари;
- повний час;
- назва дисципліни;
- шифр групи;
- вид заняття;
- аудиторія;
- тема заняття, якщо вона введена.

## Справи
- час;
- повна назва;
- категорія;
- пріоритет;
- пов'язаний проєкт, якщо є.

## Проєкти
- назва дедлайну;
- категорія;
- прогрес;
- наступний крок.

Базову висоту клітинки зменшено до 145 px.
Якщо день насичений, рядок цього тижня автоматично росте рівно настільки, скільки потрібно для всіх записів.

Також додано cache-busting `?v=9` і оновлений service worker, щоб GitHub Pages не показував стару версію з кешу.
