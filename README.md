# ФІШЕР — CONTROL v20

## Дисципліни тепер є навчальним планом

Розділ «Дисципліни» більше не лише підсумовує вже створені заняття.

Спочатку створюється ПЛАН дисципліни:
- назва;
- група;
- семестр;
- одиниця обліку;
- загальний обсяг;
- розподіл за видами занять.

## Одиниця обліку

Можна рахувати:
1. заняття / пари;
2. академічні години.

При обліку в академічних годинах одна стандартна пара = 2 академічні години.

## Види занять

Можна задати кількість:
- лекцій;
- практичних;
- лабораторних;
- семінарів;
- індивідуальних;
- заліків;
- іспитів;
- консультацій;
- репетицій;
- контрольних робіт;
- одного власного виду заняття.

CONTROL не дозволить зберегти план, якщо сума видів не дорівнює загальному обсягу.

## Зв'язок із розкладом

У формі заняття з'явилося поле «План дисципліни».

При виборі плану:
- група підставляється автоматично;
- дисципліна підставляється автоматично;
- заняття зараховується саме в цей навчальний план.

Старі заняття теж автоматично підтягуються, якщо збігаються:
- дисципліна;
- група;
- семестр.

## Контроль виконання

Для кожної дисципліни видно:
- плановий обсяг;
- скільки вже виставлено у розклад;
- скільки залишилось;
- чи є перевищення.

Кожен вид заняття контролюється ОКРЕМО.

Наприклад:
- Лекція 4 / 4
- Практичне 7 / 10
- Семінар 2 / 2

CONTROL покаже:
«Ще не все виставлено — Практичне: залишилось 3».

Якщо загальна кількість правильна, але види розподілені неправильно, дисципліна все одно не вважається завершеною.

## Де саме стоять заняття

Усередині дисципліни для кожного виду видно дати:
`03.09 · 2 пара`
`10.09 · 2 пара`
`17.09 · 3 пара`

Натискання відкриває конкретний день.

Нижче є повний список усіх занять дисципліни з:
- датою;
- парою;
- видом;
- аудиторією;
- темою;
- «Що підготувати».

## Заняття без плану

Якщо в календарі вже є заняття, але для них не створено навчального плану,
CONTROL показує окремий блок «Заняття без навчального плану»
і пропонує створити план.

Старі дані та резервні копії збережені.
