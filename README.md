# ФІШЕР — personal control v15

Виправлено повторний баг у режимі «Обрати конкретні дати».

У v14 на екрані могли одночасно бути:
- «Обрані дати: 3»
- і нижче «Ще немає обраних дат».

## Нова технічна логіка
Тепер крок 1 і крок 2 не обчислюють дати окремо.

Один і той самий локальний масив `selectedDates`:
1. малює плашки «13 сер · 20 сер · 27 сер»;
2. у ту ж мить передається в крок 2;
3. з нього будуються рядки винятків.

Тому якщо дата видима в «Обрані дати», вона фізично не може бути відсутня в кроці 2.

Для збереження серії режим «Обрати конкретні дати» також використовує напряму той самий набір вибраних дат.
