# ФІШЕР — CONTROL v21

v21 виправляє невдале складання v20.

## Як тепер працюють «Дисципліни»

Спочатку створюється навчальний план дисципліни:
- назва;
- група;
- семестр;
- загальний обсяг;
- рахунок у заняттях або академічних годинах;
- розподіл за видами занять.

Наприклад:
18 занять
- Лекція — 4
- Практичне — 10
- Семінар — 2
- Залік — 2

CONTROL не дозволяє зберегти план, якщо сума видів не дорівнює загальному обсягу.

## Потім — розклад

У формі заняття є «План дисципліни».
При виборі плану група і дисципліна підставляються автоматично.

У розділі дисципліни CONTROL показує:
- скільки вже виставлено;
- скільки залишилось;
- перевищення;
- кожен вид окремо;
- конкретні дати й номери пар;
- повний список занять.

Старі заняття автоматично підтягуються до плану, якщо збігаються:
дисципліна + група + семестр.

Якщо в календарі є заняття без плану, вони показуються окремим блоком
«Заняття без навчального плану».
