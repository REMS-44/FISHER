# ФІШЕР — personal control v5

Що змінено у v5:
- календар перероблено під помісячний вигляд, ближчий до референсу;
- зверху є вкладки місяців;
- показується один великий місяць, а не дрібні 12 місяців одразу;
- день став активним: при натисканні відкривається окремий день з усім, що там є;
- окрема вкладка тепер називається «Календар»;
- збережено всі попередні функції: заняття, справи, проєкти, нотатки, часові слоти, види занять, пошук, експорт/імпорт.
