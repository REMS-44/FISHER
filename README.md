# CONTROL — personal workspace

Статичний персональний органайзер без сервера.

## Що є
- Головна панель
- Мій тиждень
- Заняття
- Справи
- Проєкти
- Нотатки
- Глобальний пошук
- Редагування / видалення
- Експорт / імпорт резервної копії JSON
- Адаптація під телефон
- PWA-режим: після публікації сайт можна додати на головний екран телефона

## Де зберігаються дані
У localStorage браузера. Це означає:
- дані зберігаються на конкретному пристрої / браузері;
- між телефоном і компʼютером самі не синхронізуються;
- перед очищенням браузера варто зробити «Експорт даних».
