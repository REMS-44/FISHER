# ФІШЕР — personal control v10

Головна зміна: поле «Що підготувати» тепер реально використовується в інтерфейсі.

## Де видно «Що підготувати»
- прямо в картці заняття у місячному календарі;
- у блоці «Сьогодні»;
- у великому екрані окремого дня;
- у таблиці «Заняття».

## Що прибрано
Поле «Статус / Заплановано» прибрано з інтерфейсу занять.

У таблиці «Заняття» замість колонки «Статус» тепер є колонка «Що підготувати».

Також пошук тепер шукає і по тексту з поля «Що підготувати».
