# ФІШЕР — personal control v16

Головну сторінку спрощено.

## Прибрано з Головної
- дубль блоку «Заняття»;
- дубль блоку «Справи»;
- дубль блоку «Проєкти»;
- «Швидкі нотатки».

Усі ці розділи вже є окремо в меню, тому повторювати їх на Головній не було сенсу.

## На Головній залишено
- Сьогодні;
- Найближче;
- Підготувати до занять;
- повний місячний календар.

Головна тепер працює як огляд і робочий пульт, а не як дубль усіх інших сторінок.
